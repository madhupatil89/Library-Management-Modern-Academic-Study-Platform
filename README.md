# Library Management — Modern Academic & Study Knowledge Hub

A modern, working web application built for students, researchers, and academic institutions under the brand **Library Management**. Designed with a **White & Blue** aesthetic, it integrates modern study utilities and library operations into a responsive platform.

## 🚀 Key Features

### 1. 📚 Academic Catalog & Smart Search
* **Curated Volumes**: Initial catalog across Computer Science & AI, Healthcare, Engineering & Physics, Mathematics, Economics, and Literature.
* **Instant Search & Multi-Filters**: Filter by category pills, search by title/author/ISBN, filter by loan status (Available on Shelf vs Digital E-Book), and sort by rating/newest/stock.
* **Book Issue & Return Engine**: Check out physical or digital copies with real-time stock counters and a 14-day loan cycle.
* **Chapter Preview Reader Modal**: View academic summaries, curated chapter lists, and sample study excerpts.
* **Add Study Material**: Form to catalog new study volumes with instant persistence to `localStorage`.

### 2. 🪑 Interactive Study Space & Desk Reservation
* **Visual Floor Plan**: Interactive seat grid covering Silent Pods (Zone A), Collaborative Group Desks (Zone B), and High-End PC Labs (Zone C).
* **Live Status Indicator**: Visual chair nodes showing Available (Blue border), Selected (Solid blue gradient), and Occupied (Grey locked).
* **Automated Reservation Pass**: Generates a printable study ticket with assigned time slot, zone, Wi-Fi credentials, and student ID.

### 3. ⏱️ Deep Focus Suite
* **Pomodoro Focus Timer**: 25m Focus, 5m Short Break, and 15m Long Break intervals with dynamic SVG circular progress ring.
* **Synthesized Audio Chime**: Native Web Audio API chime bell rings upon session completion.
* **Study Time Tracker**: Automatically logs focus minutes to the student dashboard.
* **Study Scratchpad**: Auto-saves revision notes, formulas, and queries in real time with 1-click `.txt` file export.

### 4. 🪪 Student Dashboard & Digital Pass
* **Virtual Library Card**: Official digital student pass with barcode and department credentials.
* **Active Loans Manager**: Displays all borrowed books with due-date countdowns, 1-click **Renew (+7 Days)**, and **Return Book** actions.
* **Print Ready**: Optimized `@media print` styles for physical pass cards and desk reservation slips.

### 5. 📥 Free E-Guides & Revision Cheat Sheets
* Instant downloadable study packs (DSA Cheat Sheet, Calculus Bible, Metabolism Pathways, IEEE Citation Guide).
